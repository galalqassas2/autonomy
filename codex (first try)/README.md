# Autonomy

Premium single-page website for Autonomy, built with Next.js 15, React 19, Tailwind CSS 4, Motion, shadcn-style Radix primitives, and Iconify.

## Run locally

```bash
pnpm install
pnpm dev
```

Production verification:

```bash
pnpm typecheck
pnpm build
pnpm start
```

## Launch inputs still owned by the client

- Final logo files
- Confirmed Ireland hosting provider and region
- Real flow names, steps, scripts, and measured durations
- Legal entity, contact details, privacy policy, terms, and data processing terms
- Final licensing decision for a custom or commercial 3D icon set if dimensional Iconify plaques are not the launch treatment

The lead endpoint currently validates and acknowledges submissions in the application process. Connect it to the client's CRM or email delivery service before launch.
